      About

      aLogs: Aniiloger's Companion App — an unofficial community companion for Aniimo. Not affiliated with Aniimo or its developers.

      The meter only reads the game: its picture (built-in Windows capture), its sound during boss fights, its text log and its data files. It never changes the game's memory or files.

      On Windows 10: aLogs captures the whole screen without a border (Desktop Duplication: Windows 10 can't capture just the game window without a yellow border; Windows 11 can). So it keeps the DPS window and Sanctum Helper's map out of screen captures, or it would read its own overlays: OBS Game Capture is unaffected (it never shows overlay windows), but OBS Display Capture, screenshots and Game Bar won't show them. While you're tabbed out, aLogs copies the game window itself a few times a second instead (not while the game is minimized).

      Data folder: …

      Includes HidHide's driver by Nefarius Software Solutions (MIT License), installed only if you set up controller blocking.

      Includes Sanctum Helper by sargeeva (MIT License): an Egg Heist companion. Like the meter, it only looks at screen pixels. Map art, icons and game terms come from the game's own files and belong to their owners.

      Updates

      aLogs always checks for updates and shows them in the sidebar. Nothing installs until you choose: Install now closes aLogs, shows a progress bar while it installs and opens the new version; Next time aLogs opens installs it then. No installer to click through either way.

      Report a problem

      Sends your logs to the AniiLogs developers, one report for the whole app: the meter's log, your 20 newest fights' readings, your profile notes, Sanctum Helper's log and both modules' settings (never your sign-in), with your game UID, the time, which build you have and any screenshots you add. They're kept privately and cleared once the problem is fixed (after 30 days at most).

      Screenshots (optional)

      Up to 5, or paste one with Ctrl+V (a Win+Shift+S snip works). They're sent as they are, so crop out anything private.
